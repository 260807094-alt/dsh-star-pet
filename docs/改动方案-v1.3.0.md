## 三、三处需要你拍板的细节

### 3.1 「全空」之后，看板显示什么？

当 `work_weekdays` 和 `overtime_weekdays` 都是空数组时：
- `isWorkday` 恒 `false` → `phase` 恒 `"rest"`
- 看板状态行显示「今天休息 · 周三」
- 本月剩余工作日 = `0 天`
- 本月还可赚 = `¥0.00`（基础 0 + 加班 0）
- 金额格 `¥0.00`

**这是你想要的吗？** 还是希望空集合时显示一个特殊提示（比如「这周不上班，好好休息」）？

### 3.2 日薪格的绿+蓝怎么排？

参照「本月还可赚」的做法（`renderer.js:639-664` 现在用 flex 行 + 两个 span）。日薪格目前是 `mkEl(...)` 生成的单个 `div`，要改成 flex 容器：

```
日薪    ¥459.77 +¥172.41
       ↑绿色    ↑蓝色
```

**空间情况**：日薪值格中心在 `valCx[1] = 16 + 156*1.62 ≈ 269px`，面板内右边界 328px，左右各约 59px 余量。`¥459.77 +¥172.41` 在 12px 字号下约 115px 宽，**刚好放得下但余量很小**；月薪填到五位数（`¥45,977.00 +¥17,241.00`）就会顶到左边「日薪」标签上。

三个选择：
- **A**：日薪格只显示合计 `¥632.18`（绿色），拆解信息不显示 —— 最稳妥，但加班费不是蓝色
- **B**：拆成绿+蓝两段，字号从 12px 降到 10px（约 95px 宽）—— 符合配色要求，五位数也放得下，但和其它格字号不一致
- **C**：日薪格显示合计，把「工期基础 / 加班」拆解挪到「窝囊费」那格旁边

我倾向 **B**（配色要求优先，10px 与 `FONT.label` 同档，视觉上不算突兀）。

### 3.3 周末互斥保留，但「全空」之后互斥还有意义吗？

原逻辑（v1.2 遗留）：如果周六已经在加班日里，就不能把它加到上班日（除非加班日只有这一天，那才「抢占」）。判断式是 `blocked = steal && other.size <= 1`，`steal` 只在 `day >= 6` 时成立。

**当时发现的问题**：`other.size <= 1` 在 `other.size === 0` 时恒真 → 全空状态下周六日永远选不动。

**最终方案（用户 2026-11-09 决定：删除 blocked）**：不再有「灰色不可点」这一状态，改成纯切换 + 自动挪位：

```js
function toggleDay(day, self, other) {
    if (self.has(day)) { self.delete(day); }
    else { if (day >= 6) other.delete(day); self.add(day); }
}
```

点周六上班 → 加班日的周六自动消失；再点一下 → 取消上班日。没有第三种状态，也没有「点了没反应」。
数据侧另有 `validateConfig` 兜底：周末同时出现在两个列表就报错（防止手改 JSON 或旧配置）。

## 四、顺带修掉的三个 bug（不需要你决策）

### 4.1 `helper` 引用竞态（P0，会在连点启停时留下孤儿进程）

`lib/index.js:543-546`：
```js
helper.on("exit", (code) => {
    if (code && code !== 0) lastError = "helper 退出码 " + code;
    helper = null;   // ← 无条件清模块级引用
});
```
`stop()` 已经 `helper = null`，随后旧进程的 `exit` 事件到达，又把**新** `helper` 清空 → 下次 `isRunning()` 返回 false，`start()` 再 spawn 一个 → 两个 Electron 进程。

**改法**：闭包捕获自己的引用，只在未换人时清空：
```js
const child = spawn(...);
helper = child;
child.on("exit", (code) => {
    if (code && code !== 0) lastError = "helper 退出码 " + code;
    if (helper === child) helper = null;
});
```

### 4.2 配置热更新是死分支

`lib/index.js:679` 的 `if (helper && helper.connected)` —— `spawn()` 返回的 `ChildProcess` 没有 `connected`/`send`（那是 `fork()`/IPC 的特有属性），这条分支永远不会执行。实际生效靠 renderer 每 250ms 轮询 `/config`。

**改法**：删掉这段，把注释改成「配置由渲染端轮询生效，此处无需通知」。

### 4.3 时间非法中间态

时间字段的 `min`/`max` 只控制按钮灰态，不夹取当前值。比如午休加到 300 分钟后，午休开始的上限变成 12:00，但值还可能停在 15:30。

**改法**：在 `stepper` 的 `refresh()` 里，如果 `v < lo()` 或 `v > hi()`，直接 `set(clamp(v))`。
